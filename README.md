# Listening practice (mod_whakaharatau)

*Whakaharatau* is te reo Māori for "practise, rehearse".

A Moodle activity for listening practice with pictures. Each slide shows an image and a set of
audio clips. The learner plays the clips and chooses the one that matches the picture; the
server marks the answer. Teachers build an activity by uploading images and audio files (one at
a time, or in bulk as a ZIP), and choose:

- **Practice** (default, ungraded) or **Test** (graded) mode,
- shuffle on or off, and repeat off, all, or missed slides only (Practice),
- fixed or random option order, tries per slide, feedback after each answer or only at the end,
- scoring by correct answers or by slides completed, attempts allowed and grading method (Test),
- a progress bar, autoplay of a slide's prompt audio, transcripts before answering,
- whether the activity runs inline on the course page as well as on its own page.

Site administrators set the defaults (with "Advanced" and "Locked" flags) under
*Site administration > Plugins > Activity modules > Listening practice*.

## Requirements

Moodle 5.2 or 5.3.

## Installation

Copy this folder to `mod/whakaharatau` in your Moodle code (under `public/` on Moodle 5.1 and
later), then visit *Site administration > Notifications* to finish the installation.
